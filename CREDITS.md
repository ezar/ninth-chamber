Recorded sound and music under open licences. The full list, file by file with source links, is in [public/audio/CREDITS.md](public/audio/CREDITS.md) (also served with the game at `audio/CREDITS.md`); `scripts/audio/build_audio.py` rebuilds every file from these sources.
